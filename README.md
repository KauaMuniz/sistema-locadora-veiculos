# 🚗 Sistema Locadora de Veículos

Sistema de locadora de veículos desenvolvido em Python com o objetivo de aplicar conceitos de lógica de programação, manipulação de arquivos, controle de dados e, futuramente, tecnologias amplamente utilizadas no mercado como MySQL, Programação Orientada a Objetos (POO) e APIs REST.

## 📖 Sobre o Projeto

Este projeto simula o funcionamento de uma locadora de veículos, permitindo o gerenciamento completo dos automóveis cadastrados através de operações CRUD (Create, Read, Update e Delete).

A aplicação foi desenvolvida inicialmente utilizando armazenamento em arquivos TXT para consolidar conceitos fundamentais de programação. A evolução do projeto prevê a migração para um banco de dados MySQL, implementação de Programação Orientada a Objetos, sistema de locação de veículos, integração com APIs externas e desenvolvimento de uma API própria.

## ✨ Funcionalidades Atuais

- Cadastro de veículos
- Listagem de veículos cadastrados
- Alteração de informações dos veículos
- Exclusão de veículos por ID
- Pesquisa de veículos por valor
- Geração de relatório individual por ID
- Validação de dados de entrada
- Persistência de dados em arquivo TXT
- Interface de terminal com menu interativo

```bash

```

Acesse a pasta do projeto:

```bash

```
